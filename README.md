# TUTORIAL_ROUND_1

Clean project layout for strategy development, analysis, and submission artifacts.

## Folder Structure

- `code/` - Trading bot and runnable Python scripts
- `data/` - Sample CSV market data
- `analysis/` - Data analysis utilities
- `notebooks/` - Jupyter notebooks
- `docs/` - Documentation and guides
- `submissions/` - Archived submission outputs/logs
- `.vscode/` - Local editor settings

## Quick Run Commands

From workspace root:

```powershell
python code/test_strategy.py
python analysis/analyze_data.py
python analysis/analyze_variation.py
python code/backtest.py
```

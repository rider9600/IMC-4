┌─ HOW THE STRATEGY WORKS ──────────────────────────────────────────────────────┐
│                                                                               │
│  📈 MEAN-REVERSION TRADING                                                   │
│                                                                               │
│     CONCEPT: Prices bounce around an average and revert when they deviate    │
│                                                                               │
│     ALGORITHM:                                                                │
│     1. Maintain rolling average of recent mid-prices (50 observations)       │
│     2. For each product, calculate current mid-price (avg of bid/ask)        │
│     3. Generate buy signal when: price < 98% × average (TOMATOES)           │
│                          or: price < 99.5% × average (EMERALDS)             │
│     4. Generate sell signal when: price > 102% × average (TOMATOES)         │
│                           or: price > 100.5% × average (EMERALDS)           │
│     5. Send orders to exchange, limit to position maxima                     │
│     6. Track trades and persist state for next iteration                     │
│                                                                               │
│  PRODUCTS & STRATEGIES:                                                       │
│                                                                               │
│     TOMATOES (Volatile, ~5000 price)                                         │
│     ├─ Range: 4946 - 5036                                                     │
│     ├─ Volatility: HIGH (19.75 std dev)                                       │
│     └─ Strategy: AGGRESSIVE mean-reversion (2% thresholds)                    │
│                                                                               │
│     EMERALDS (Stable, ~10000 price)                                          │
│     ├─ Range: 9996 - 10004                                                    │
│     ├─ Volatility: LOW (0.72 std dev)                                         │
│     └─ Strategy: CONSERVATIVE mean-reversion (0.5% thresholds)               │
│                                                                               │
